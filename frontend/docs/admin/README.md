# Admin frontend

Ứng dụng quản trị React/Vite của ProjectLTWeb. Cài dependencies tại thư mục `frontend`.

```powershell
cd frontend
npm run dev
npm run build
```

Dev server chạy tại `http://localhost:5173/admin`. API mặc định dùng backend ở `http://localhost:8081`; có thể thay đổi bằng biến `VITE_API_BASE_URL`.
